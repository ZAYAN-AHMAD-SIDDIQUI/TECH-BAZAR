## 🔍 Overview

**TECH-BAZAR** is a scalable Laravel-based e-commerce platform that provides a modern shopping experience along with powerful admin controls, analytics, and secure transactions.

---

## ✨ Key Features

### 🎨 UI / UX
- Responsive design (mobile, tablet, desktop)
- Easy navigation with categories & search
- Product filtering & sorting
- Wishlist support
- Product reviews & ratings

### 🛒 Shopping
- Add to cart & cart management
- Save items for later
- Secure checkout
- Multiple payment options (Cards, COD)

### 👤 User Accounts
- Registration & login
- Order history & reorder
- Address management

### 📊 Reports & Analytics
- Sales reports
- Best-selling products
- Inventory insights

### 🔒 Security
- Secure authentication
- Optional Two-Factor Authentication (2FA)
- Role-based access control

### 🧑‍💬 Customer Support
- Live chat
- Help center (FAQs)
- Contact forms

### 🚚 Shipping
- Real-time shipping cost calculation
- Location-based shipping rules

---

## 🛠 Admin Features

- Category & subcategory management
- Drag-and-drop category sorting
- Brand management
- Product & inventory management
- Order processing & tracking
- Discount & coupon management
- Review moderation & responses
- Shipping rate configuration
- Detailed admin reports
